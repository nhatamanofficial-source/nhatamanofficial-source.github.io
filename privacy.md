# Privacy Policy – Nha Tam An Uploader

Effective date: 15 November 2026

## 1. Who we are

Nha Tam An Uploader is an internal tool operated by the owner of the Nhà Tâm An channel. Contact: nhataman.official@gmail.com

## 2. Who uses it

Only the channel owner. No other people sign in to or use this tool.

## 3. What data it accesses

With the owner's permission (Google OAuth), the tool accesses only the owner's own YouTube channel, to upload videos and set their titles, descriptions and publishing times. It does not collect, read or store data about viewers or any other users.

## 4. How data is stored

Access tokens are stored only on the owner's own computer. They are never sold, shared or sent to third parties.

## 5. YouTube API Services

This tool uses YouTube API Services. By using it you agree to the [YouTube Terms of Service](https://www.youtube.com/t/terms). The [Google Privacy Policy](https://policies.google.com/privacy) also applies.

## 6. Revoking access

Access can be removed at any time at [https://security.google.com/settings/security/permissions](https://security.google.com/settings/security/permissions)

## 7. Changes

If this policy changes, the new version will be posted on this page with a new effective date.
